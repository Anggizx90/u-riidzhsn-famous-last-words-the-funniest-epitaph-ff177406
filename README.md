One line of famous last words, carved as a tombstone epitaph: the dead person settling their own accounts with the afterlife — an apology owed to heaven's bouncer, and a drink owed to hell's. A single line of dying speech (88 characters), written by `main.ts` to `entry.txt` for make.fun's **Famous Last Words: The Funniest Epitaph** bounty, where a judge model picks the line that gets the biggest laugh.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program is deterministic (Node 22, standard library only, no network, no clock, no randomness) and writes exactly one line — no trailing newline — to `entry.txt`, with an inline gate check enforcing the competition's 1–150 character cap.
